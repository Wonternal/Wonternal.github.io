Space War

Shooter vertical arcade en Python. Oleadas de enemigos, power-ups y estética neón. Instálalo y juega en local con Pygame CE.

  • Python 3.10+
  • Pygame CE
  • Arcade
Ver en GitHub Cómo ejecutar
Ejecutar Space War en tu PC 
git clone https://github.com/Wonternal/space-war.git
cd space-war
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
python -m space_war
